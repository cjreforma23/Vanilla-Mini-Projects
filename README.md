# Vanilla Calculator

Simple calculator using plain HTML, CSS, and JavaScript.

How to run

- Open `index.html` in your browser (double-click or use "Open File...").
- Or serve the folder with a simple static server, e.g.:

```bash
# Python 3
python -m http.server 8000

# then open http://localhost:8000 in your browser
```

Files
- index.html — UI
- styles.css — styles
- script.js — calculator logic and keyboard support
